## 📌 Apresentação Oficial em HTML (16:9)

Apresentação completa de identidade de marca e manual de diretrizes para **A Casa das Coisas Vivas**, projetada em formato web 16:9 widescreen responsivo com transições fluidas, HUD interativo, galeria de mockups com vídeo 1080p nativo e tipografia editorial de alto padrão.

### 🌟 Arquivos Principais:
1. **[`index.html`](./index.html)** — Versão principal vinculada aos assets externos (`assets/css/` e `assets/js/`).
2. **[`apresentacao-standalone.html`](./apresentacao-standalone.html)** — Versão *All-in-One* com todo CSS e JavaScript embutidos para abertura rápida e offline.
